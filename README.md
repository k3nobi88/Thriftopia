# Thriftopia – Mobile Application
Thriftopia is a mobile application designed as a platform for buying and selling second-hand fashion items.

## Project Overview
This project was developed as part of my academic project to explore mobile application development and user-friendly interface design.

## Features
* Browse second-hand fashion items
* View product details
* Search and explore products
* User profile
* Shopping cart
* Simple and user-friendly interface

## Technologies
* Android Studio
* Java
* Firebase

## Project Status
Academic project / prototype.
